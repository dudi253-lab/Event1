Security note:
v0.2 keeps database mutations behind short-lived staff session tokens and RPC checks.
For this development milestone the Storage buckets are public so approved images can be viewed
without a server-side service key. Object filenames are random, and the public album only lists
database rows with status=approved. Before production, move pending/private originals behind
private signed URLs or a server route using a secret server-side key.
